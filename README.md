🛍️ Customer Shopping Behavior Analysis | Power BI
📌 Project Overview
This project explores customer shopping behavior using Microsoft Power BI. The report transforms shopping transaction data into interactive dashboards to help understand sales performance, customer preferences, purchasing patterns, product categories, and order delivery.

The report is organized into multiple pages, including an Executive Overview, Sales Dashboard, and Orders & Delivery Dashboard.
🎯 Project Objectives
- Monitor overall sales and transaction performance
- Understand customer demographics and shopping patterns
- Compare sales across product categories and brands
- Explore payment method preferences
- Analyze purchase trends over time
- Review online versus offline shopping
- Examine order quantity and delivery speed
- Track return rate and profit-related metrics

📈 Key Metrics
The report includes measures and indicators such as:
- Total Sales — overall purchase amount
- Total Transactions — number of shopping transactions
- Total Customers — customer count
- Average Purchase Amount — average value of a purchase
- Total Quantity — quantity purchased
- Profit — profit metric included in the report
- Return Rate — return-related performance indicator
Metric values will change based on the filters and selections applied in Power BI.
